A Deep Dive CI/CD, three ways.

Jenkins, GitLab CI, and GitHub Actions. The three pipeline tools you're most likely to meet — and they don't agree on much. This tutorial starts with the concepts that all three share, then dissects each in its own idiom, then pits them against each other on the same real project. By the end you'll read any pipeline file in the wild and know what it's doing.

14 chapters 3 tools 80+ exercises 50 interview Qs

How to use this tutorial

You'll learn by doing, not just reading. Every chapter contains:

  • Concept prose — the why behind the feature.
  • Annotated pipeline snippets — Jenkinsfile, .gitlab-ci.yml, and workflow.yml examples with copy buttons.
  • Hands-on blocks — real commands to type, with expected output.
  • Pitfalls — the traps that eat afternoons.
  • Exercises with collapsible solutions. Don't peek.
Prerequisites
  • Git fundamentals (branches, commits, pushes).
  • Comfort with YAML. (If not, we'll catch you up.)
  • Shell basics — you should read curl | bash and feel nothing.
  • Docker basics for most hands-on work. Install Docker Desktop or colima if you haven't.
  • A GitHub account (free tier is enough) for the GitHub Actions chapters.
  • A GitLab account on gitlab.com (free) for the GitLab CI chapters.
  • Docker-based Jenkins for local Jenkins work — we walk you through it.

What you will learn

  • Read and write pipelines fluently in all three tools.
  • Think in pipelines: stages, jobs, artifacts, caches, triggers — and when each matters.
  • Set up Jenkins agents, GitLab runners, and GitHub runners — self-hosted and managed.
  • Securely handle secrets across all three, including OIDC-based cloud auth that eliminates long-lived credentials.
  • Build a real release pipeline: lint, test, build, scan, package, publish, deploy — three times, once per tool.
  • Answer interview questions about CI/CD with confidence — the Big 50 are in Chapter 13.

What this tutorial is not

This is not an admin manual for any one tool. For operational detail (tuning Jenkins for 10k jobs; running GitLab self-hosted; debugging GHA runner networking), the official docs are exhaustive and we link to them. This tutorial teaches how to think about pipelines — the concepts that let you reach for the right feature in any of the three tools, read their docs efficiently, and diagnose problems with understanding rather than by cargo-cult.
