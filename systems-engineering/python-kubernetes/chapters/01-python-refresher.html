Chapter 01 Python Refresher

You know Python. This chapter brushes off the parts that matter for automation work — type hints, error handling, comprehensions, dataclasses, context managers, and a handful of idioms that separate "writes Python" from "writes good Python". Skim, hit the exercises, move on.

Pin your Python version

Use Python 3.11 or 3.12 unless something forces older. Many automation idioms (structural pattern matching, exception groups, better error messages, typing.Self) only land in 3.10+.

$ python3 --version
Python 3.12.3
$ python3 -c "import sys; print(sys.version_info)"
sys.version_info(major=3, minor=12, micro=3, releaselevel='final', serial=0)

Manage versions with pyenv, asdf, or uv python install. Avoid system Python for project work — it's owned by the OS and breaks if you pip install --user too aggressively.

Virtual environments, briefly

$ python3 -m venv .venv
$ source .venv/bin/activate
(.venv) $ pip install requests pyyaml
(.venv) $ pip freeze > requirements.txt
(.venv) $ deactivate

Or with uv (fast, modern):

$ uv venv
$ source .venv/bin/activate
$ uv pip install requests pyyaml
$ uv pip compile pyproject.toml -o requirements.lock

Rule: one venv per project, never global, never sudo pip. We cover packaging in depth in Chapter 5.

Type hints — actually use them

Python is dynamic but type hints are now table stakes. They cost almost nothing, give you IDE auto-complete, and catch a class of bugs at parse time via mypy / pyright.

from pathlib import Path

def load_config(path: Path, strict: bool = True) -> dict[str, str]:
    """Read a config file as a flat string→string map."""
    text = path.read_text()
    out: dict[str, str] = {}
    for line in text.splitlines():
        line = line.strip()
        if not line or line.startswith('#'):
            continue
        if '=' not in line:
            if strict:
                raise ValueError(f"bad line: {line!r}")
            continue
        k, v = line.split('=', 1)
        out[k.strip()] = v.strip()
    return out

Note dict[str, str] not Dict[str, str] — Python 3.9+. Drop the from typing import Dict bloat.

Common types you'll write

from collections.abc import Iterable, Iterator, Sequence, Mapping, Callable
from typing import Any, Optional, Union, TypeAlias

# Modern (3.10+)
PathLike: TypeAlias = str | Path
Result: TypeAlias = dict[str, Any]

def first(items: Iterable[int]) -> int | None:    # union type
    for x in items:
        return x
    return None

def apply(fn: Callable[[int], str], xs: Sequence[int]) -> list[str]:
    return [fn(x) for x in xs]

Conventions:

  • Prefer X | None over Optional[X] on 3.10+.
  • Prefer X | Y over Union[X, Y].
  • Use collections.abc.Iterable for "anything you can iterate over once" instead of List[X] when you're accepting a parameter.
  • Use Sequence when you need indexing but not mutation.
  • Reserve concrete types (list, dict) for return types or local variables.

Dataclasses

For "a record with named fields and no behaviour", use @dataclass instead of writing __init__, __repr__, __eq__ by hand.

from dataclasses import dataclass, field
from datetime import datetime

@dataclass
class BuildResult:
    sha:        str
    image:      str
    started_at: datetime
    duration_s: float
    success:    bool
    artifacts:  list[str] = field(default_factory=list)

r = BuildResult(
    sha="3f2a1c0",
    image="firmware:1.0.0",
    started_at=datetime.utcnow(),
    duration_s=812.4,
    success=True,
    artifacts=["firmware.img", "firmware.sig"],
)
print(r)
# BuildResult(sha='3f2a1c0', image='firmware:1.0.0', ...)

Variants:

@dataclass(frozen=True)         # immutable, hashable — use as dict keys
class Sha:
    value: str

@dataclass(slots=True)          # smaller memory, faster attribute access
class Pixel:
    x: int
    y: int
    color: str

@dataclass(kw_only=True)        # force keyword arguments — call sites are clearer
class Promotion:
    artifact: str
    target_channel: str
    requested_by: str
field(default_factory=list) not = []

The classic Python gotcha: def f(x=[]): shares the same list across calls. Same in dataclasses — never write artifacts: list[str] = [] as a default. Use field(default_factory=list).

Errors — raise specific, catch specific

# BAD — too broad, swallows real bugs
try:
    do_thing()
except Exception:
    pass

# GOOD — narrow exception, narrow recovery
try:
    config = load_config(path)
except FileNotFoundError:
    log.warning("no config; using defaults")
    config = {}
except ValueError as e:
    log.error("config malformed: %s", e)
    raise SystemExit(2) from e

Define your own exception types when a caller might want to distinguish:

class PromotionError(Exception):
    """Base class for all promotion errors."""

class AlreadyPromotedError(PromotionError):
    """Idempotent no-op signal — already at target channel."""

class PromotionForbidden(PromotionError):
    """Caller does not have permission to promote to this channel."""

# Caller can do narrow handling:
try:
    promote(artifact, channel="release")
except AlreadyPromotedError:
    log.info("already promoted, nothing to do")
except PromotionForbidden as e:
    log.error("forbidden: %s", e)
    raise SystemExit(3)

The raise X from Y pattern

Preserve the exception chain when wrapping:

try:
    data = json.loads(text)
except json.JSONDecodeError as e:
    raise PromotionError(f"manifest is not valid JSON: {e}") from e

The traceback will show the original cause, which is essential for debugging.

Comprehensions, the right ones

# list comprehension
squares = [n * n for n in range(10)]

# with filter
positives = [x for x in numbers if x > 0]

# dict comprehension
by_sha = {b.sha: b for b in builds}

# set comprehension
unique_authors = {commit.author for commit in commits}

# generator expression — no list materialised, lazy
total = sum(b.duration_s for b in builds)        # no [] inside sum()

Two refactor cues:

  • If a for loop appends to a list, it's almost always a comprehension.
  • If you find yourself writing nested comprehensions deeper than one level, stop — extract a function. Readability matters more than density.
Generator vs list — the sum([…]) mistake

sum([n*n for n in range(10**7)]) materialises a 10-million-item list in memory.
sum(n*n for n in range(10**7)) streams. Same answer, fraction of the memory. Drop the brackets when consuming with sum, min, max, any, all.

Context managers

with blocks make resource lifetime explicit. Use them for files, locks, connections, temp dirs — anything that needs cleanup.

with open('manifest.json') as f:
    data = json.load(f)
# file is closed here, even if json.load raised

# Multiple at once
with open('a.txt') as a, open('b.txt') as b:
    diff = compare(a, b)

Write your own with contextlib:

from contextlib import contextmanager
from pathlib import Path
import os

@contextmanager
def cd(path: Path):
    """Temporarily chdir, restore on exit."""
    prev = Path.cwd()
    os.chdir(path)
    try:
        yield path
    finally:
        os.chdir(prev)

with cd(Path('/tmp/build')):
    subprocess.run(['make', '-j8'], check=True)
# back in original cwd here

Generators

A function with yield instead of return is a generator — produces values on demand. Use for anything streamy or memory-bound.

def tail_log(path: Path) -> Iterator[str]:
    """Yield each new line as it's written, like `tail -f`."""
    with path.open() as f:
        f.seek(0, 2)                      # end of file
        while True:
            line = f.readline()
            if line:
                yield line.rstrip()
            else:
                time.sleep(0.1)

for line in tail_log(Path('/var/log/build.log')):
    if 'ERROR' in line:
        notify(line)

Generators are also how you process huge files without loading them:

def parse_records(path: Path) -> Iterator[dict]:
    with path.open() as f:
        for line in f:
            yield json.loads(line)

# 10 GB JSONL file, constant memory
for rec in parse_records(Path('events.jsonl')):
    process(rec)

Iteration tricks worth memorising

# enumerate — give me index AND value
for i, line in enumerate(lines, start=1):
    print(f"{i:4d}  {line}")

# zip — walk multiple iterables in lockstep
for src, dst in zip(sources, destinations, strict=True):    # 3.10+ strict=
    copy(src, dst)

# unpack — leftovers go to *rest
first, *middle, last = ['a', 'b', 'c', 'd', 'e']
# first='a', middle=['b','c','d'], last='e'

# chain — flatten one level
from itertools import chain
all_files = list(chain.from_iterable(d.iterdir() for d in dirs))

# groupby (NOTE: needs sorted input)
from itertools import groupby
items.sort(key=lambda x: x.channel)
for channel, group in groupby(items, key=lambda x: x.channel):
    print(channel, list(group))

Structural pattern matching (3.10+)

def handle_event(event: dict) -> str:
    match event:
        case {"type": "push", "branch": "main"}:
            return "trigger main pipeline"
        case {"type": "push", "branch": branch} if branch.startswith("release/"):
            return f"trigger release pipeline for {branch}"
        case {"type": "pull_request", "action": "opened"}:
            return "open PR pipeline"
        case {"type": "pull_request"}:
            return "ignore other PR events"
        case _:
            return f"unknown event: {event!r}"

Cleaner than nested if/elif for shapes. Patterns can also match types, sequences, and class instances. Don't go wild — for two cases, if is still clearer.

f-strings, properly

name = "world"
msg = f"Hello, {name}!"

# expressions
r = 7
print(f"area={3.14159*r*r:.2f}")             # area=153.94

# format specs
print(f"{42:08d}")                            # 00000042
print(f"{0.123456:.3%}")                      # 12.346%
print(f"{1_234_567:,}")                       # 1,234,567

# !r for repr (great for log messages with surprising whitespace)
val = "  hi  "
log.error(f"unexpected value: {val!r}")        # unexpected value: '  hi  '

# 3.8+ self-documenting
x = 42
print(f"{x=}")                                # x=42

Logging — never print in real code

Production rule: print goes to stdout, no severity, no timestamps, no module name, can't be silenced. Use the standard logging module.

import logging

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)-7s %(name)s | %(message)s",
)
log = logging.getLogger(__name__)

log.debug("verbose detail; usually off in prod")
log.info("normal progress")
log.warning("something fishy but we continued")
log.error("something failed")
log.exception("auto-logs traceback inside an except block")

Structured logging — for anything CI/automation, log JSON with context fields:

import json, logging

class JSONFormatter(logging.Formatter):
    def format(self, record):
        return json.dumps({
            "ts":     self.formatTime(record),
            "level":  record.levelname,
            "logger": record.name,
            "msg":    record.getMessage(),
            **getattr(record, "extra_fields", {}),
        })

# Usage:
log.info("promoted artifact",
         extra={"extra_fields": {"sha": "3f2a1c0", "channel": "staging"}})

Ten idioms that mark a "good" Python writer

  1. Use pathlib.Path, not string paths. Path('/tmp') / 'foo' / 'bar.txt'.
  2. Walrus operator := for "compute once, test, use" — but sparingly.
  3. with for everything that has cleanup — files, locks, sockets, temp dirs.
  4. EAFP, not LBYL. "Easier to ask forgiveness than permission" — try/except beats checking if path.exists() then opening.
  5. collections.defaultdict instead of if k not in d: d[k] = ….
  6. collections.Counter for histograms in one line.
  7. functools.lru_cache for memoisation.
  8. enum.Enum for fixed sets of values, not magic strings.
  9. Unpacking over indexing — first, *_, last = items.
  10. Comprehensions over map/filter — they read more naturally in Python.

Exercises

EX 1.1 easy Type-hint a function

Add type hints to:

def merge(a, b, prefer=None):
    out = {}
    out.update(a)
    out.update(b)
    if prefer:
        out.update(prefer)
    return out
Show solution 
from collections.abc import Mapping
from typing import Any

def merge(
    a: Mapping[str, Any],
    b: Mapping[str, Any],
    prefer: Mapping[str, Any] | None = None,
) -> dict[str, Any]:
    out: dict[str, Any] = {}
    out.update(a)
    out.update(b)
    if prefer:
        out.update(prefer)
    return out

Why Mapping not dict for inputs: any read-only-mappable accepts. Why dict for return: callers should know they get a real dict (mutable, indexable).

EX 1.3 medium Define an exception hierarchy

Design exceptions for an artifact-promotion library: a base, plus distinct subclasses for "artifact missing", "channel forbidden", "checksum mismatch". Show a caller doing narrow handling.

Show solution 
class PromotionError(Exception):
    """Base for promotion failures."""

class ArtifactNotFound(PromotionError):
    pass

class ChannelForbidden(PromotionError):
    pass

class ChecksumMismatch(PromotionError):
    def __init__(self, expected: str, actual: str):
        super().__init__(f"checksum mismatch: expected {expected}, got {actual}")
        self.expected = expected
        self.actual   = actual

# Caller
try:
    promote(name, channel="release")
except ArtifactNotFound as e:
    log.error("artifact missing: %s", e); raise SystemExit(2)
except ChannelForbidden as e:
    log.error("not allowed: %s", e); raise SystemExit(3)
except ChecksumMismatch as e:
    log.error("integrity check failed: %s", e); raise SystemExit(4)
except PromotionError as e:
    log.exception("unexpected promotion failure")
    raise SystemExit(1)
EX 1.4 medium Write a context manager

Write timed("name") as a context manager that logs how long the block took on exit.

Show solution 
from contextlib import contextmanager
import time, logging

log = logging.getLogger(__name__)

@contextmanager
def timed(label: str):
    t0 = time.monotonic()
    try:
        yield
    finally:
        log.info("%s took %.3fs", label, time.monotonic() - t0)

with timed("build image"):
    subprocess.run(["bitbake", "core-image-base"], check=True)

Note time.monotonic() not time.time() — the former never goes backwards on clock adjustments.

EX 1.5 medium Generator for batched processing

Write batched(iterable, n) that yields tuples of n items at a time (last tuple may be shorter). 3.12 has it built in as itertools.batched — write the equivalent.

Show solution 
from collections.abc import Iterable, Iterator
from typing import TypeVar

T = TypeVar("T")

def batched(it: Iterable[T], n: int) -> Iterator[tuple[T, ...]]:
    if n < 1:
        raise ValueError("n must be >= 1")
    buf: list[T] = []
    for x in it:
        buf.append(x)
        if len(buf) == n:
            yield tuple(buf); buf = []
    if buf:
        yield tuple(buf)

list(batched(range(7), 3))   # [(0,1,2), (3,4,5), (6,)]
EX 1.6 hard Frozen dataclass as dict key

Why does @dataclass(frozen=True) let an instance be used as a dict key, while a regular dataclass doesn't? Demonstrate with a small example, including the failure.

Show solution

Default dataclasses are mutable and Python forbids hashing mutable objects (their hash could change while they're in the dict, breaking lookup). frozen=True generates __hash__ based on the field values and disables __setattr__.

from dataclasses import dataclass

@dataclass
class M:
    x: int

@dataclass(frozen=True)
class F:
    x: int

d = {}
d[F(1)] = "ok"               # works
try:
    d[M(1)] = "fails"
except TypeError as e:
    print("expected:", e)    # unhashable type: 'M'

Side benefit: frozen dataclasses are safer to share across threads.

EX 1.7 hard Refactor with match

Rewrite using structural pattern matching:

def parse(item):
    if isinstance(item, dict) and item.get("kind") == "Pod":
        return f"pod {item['metadata']['name']}"
    elif isinstance(item, dict) and item.get("kind") == "Service":
        return f"svc {item['metadata']['name']}"
    elif isinstance(item, list):
        return f"list of {len(item)}"
    else:
        return "unknown"
Show solution 
def parse(item) -> str:
    match item:
        case {"kind": "Pod",     "metadata": {"name": name}}: return f"pod {name}"
        case {"kind": "Service", "metadata": {"name": name}}: return f"svc {name}"
        case list() as xs:                                   return f"list of {len(xs)}"
        case _:                                              return "unknown"

Reads top-down as a decision table. The {...} patterns also bind nested keys — no manual ['metadata']['name'] indexing.

Recap

  • Modern Python (3.10+) with type hints is the default. Use built-in generics (list[X]) and X | None.
  • Dataclasses for records; frozen=True for hashable; field(default_factory=…) for mutable defaults.
  • Raise specific, catch specific. Use raise X from Y to preserve the chain. Define a typed exception hierarchy for libraries.
  • Generator expressions and yield for streaming and memory-bound work.
  • with + contextlib.contextmanager for any resource lifecycle.
  • Structural pattern matching for tag-shaped dispatch.
  • Stop using print. Use logging.
