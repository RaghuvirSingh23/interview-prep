Chapter 14 Capstone — A Python Promotion Bot Running in Kubernetes

We'll build a small Python tool that promotes artifacts between channels (dev → staging) by polling Artifactory and creating K8s Jobs in the cluster. It uses every pattern from the previous chapters — typed Python, retries, idempotency, CLI, packaging, containerisation, RBAC, ConfigMap/Secret, CronJob. Real-shape automation in ~200 lines.

What we'll build

Imagine: every n minutes, an automation needs to:

  1. List all artifacts in the dev channel.
  2. For each that has been validated (an annotation says so), promote it to staging.
  3. Record what was promoted; never re-promote.
  4. Trigger a "smoke test" K8s Job to validate the promoted artifact.
  5. Report success/failure to a Slack channel.

Scope: this exact pattern is the unsung hero of every embedded CI/CD pipeline, because the alternative is humans clicking buttons in Artifactory at 2 AM.

Config (Pydantic settings)

pythonsrc/promote_bot/config.py
from pathlib import Path
from pydantic import Field
from pydantic_settings import BaseSettings, SettingsConfigDict
import yaml

class Settings(BaseSettings):
    """Loaded from env (PROMOTE_*) and/or a config YAML."""
    nexus_url:    str = Field(...)
    nexus_token:  str = Field(...)               # via Secret
    src_channel:  str = "dev"
    dst_channel:  str = "staging"
    label:        str = "qa-approved"
    dry_run:      bool = False
    slack_webhook: str | None = None              # optional, via Secret
    namespace:    str = "promote"
    smoke_image:  str = "registry.example.com/smoke:1.0"

    model_config = SettingsConfigDict(
        env_prefix="PROMOTE_",
        case_sensitive=False,
    )

def load_extra_yaml(settings: Settings, path: Path) -> Settings:
    """Optional override from a config YAML mounted as a ConfigMap."""
    if not path.exists():
        return settings
    extras = yaml.safe_load(path.read_text()) or {}
    return settings.model_copy(update=extras)

Artifactory client

pythonsrc/promote_bot/artifactory.py
from __future__ import annotations
import logging
from dataclasses import dataclass
from requests import Session
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

log = logging.getLogger(__name__)

@dataclass(frozen=True)
class Artifact:
    name: str
    sha:  str
    channel: str
    qa_approved: bool

class Artifactory:
    def __init__(self, base_url: str, token: str):
        self.base = base_url.rstrip('/')
        self.s = Session()
        self.s.headers.update({"Authorization": f"Bearer {token}",
                                "Accept": "application/json",
                                "User-Agent": "promote-bot/1.0"})
        retry = Retry(
            total=5, backoff_factor=0.5,
            status_forcelist=(429, 500, 502, 503, 504),
            allowed_methods=("GET", "PUT", "POST", "DELETE"),
            respect_retry_after_header=True,
        )
        self.s.mount("https://", HTTPAdapter(max_retries=retry, pool_maxsize=20))

    def list_artifacts(self, channel: str) -> list[Artifact]:
        r = self.s.get(f"{self.base}/api/repositories/{channel}-local/items",
                       timeout=(5, 30))
        r.raise_for_status()
        items = r.json().get("items", [])
        return [Artifact(
            name=i["name"], sha=i["properties"].get("sha", ""),
            channel=channel,
            qa_approved=i["properties"].get("qa-approved", "false").lower() == "true",
        ) for i in items]

    def already_promoted(self, name: str, channel: str) -> bool:
        r = self.s.get(f"{self.base}/api/storage/{channel}-local/{name}",
                       timeout=(5, 15))
        return r.status_code == 200

    def promote(self, name: str, src: str, dst: str) -> None:
        r = self.s.post(
            f"{self.base}/api/copy/{src}-local/{name}",
            params={"to": f"/{dst}-local/{name}"},
            timeout=(5, 60),
        )
        r.raise_for_status()
        log.info("promoted %s: %s → %s", name, src, dst)

Kubernetes client (the official Python SDK)

pythonsrc/promote_bot/k8s.py
from __future__ import annotations
import logging
from kubernetes import client, config
from kubernetes.client.rest import ApiException

log = logging.getLogger(__name__)

def load_config():
    """Try in-cluster first; fall back to ~/.kube/config (for dev)."""
    try:
        config.load_incluster_config()
        log.info("using in-cluster config")
    except config.ConfigException:
        config.load_kube_config()
        log.info("using ~/.kube/config")

def submit_smoke_job(namespace: str, sha: str, image: str) -> str:
    job_name = f"smoke-{sha[:8]}"
    body = {
        "apiVersion": "batch/v1",
        "kind": "Job",
        "metadata": {
            "name": job_name,
            "namespace": namespace,
            "labels": {
                "app": "smoke-test",
                "promote-bot/sha": sha[:8],
            },
        },
        "spec": {
            "backoffLimit": 1,
            "ttlSecondsAfterFinished": 86400,
            "template": {
                "spec": {
                    "restartPolicy": "Never",
                    "containers": [{
                        "name": "smoke",
                        "image": image,
                        "args": ["--sha", sha],
                        "resources": {
                            "requests": {"cpu": "100m", "memory": "128Mi"},
                            "limits":   {              "memory": "128Mi"},
                        },
                    }],
                }
            },
        },
    }

    batch = client.BatchV1Api()
    try:
        batch.create_namespaced_job(namespace=namespace, body=body)
        log.info("created Job %s", job_name)
    except ApiException as e:
        if e.status == 409:
            log.info("Job %s already exists (idempotent)", job_name)
        else:
            raise
    return job_name

Note the 409-handling — that's idempotency. If the bot ran 30 seconds ago and the Job exists, treat as success; never duplicate.

Slack notifier

pythonsrc/promote_bot/slack.py
import logging, requests

log = logging.getLogger(__name__)

def notify(webhook: str | None, text: str, ok: bool = True) -> None:
    if not webhook:
        log.info("no slack webhook; skipping notify: %s", text)
        return
    payload = {"text": ("✅ " if ok else "❌ ") + text}
    try:
        r = requests.post(webhook, json=payload, timeout=(3, 10))
        r.raise_for_status()
    except requests.RequestException as e:
        # Don't fail the whole run for a slack outage
        log.warning("slack notify failed: %s", e)

The reconciler

pythonsrc/promote_bot/promoter.py
from __future__ import annotations
import logging, time
from .artifactory import Artifactory, Artifact
from .config import Settings
from .k8s import submit_smoke_job
from .slack import notify

log = logging.getLogger(__name__)

def reconcile(s: Settings) -> tuple[int, int]:
    """One pass: returns (n_promoted, n_failed)."""
    art = Artifactory(s.nexus_url, s.nexus_token)
    candidates = art.list_artifacts(s.src_channel)
    log.info("found %d in %s", len(candidates), s.src_channel)

    eligible = [a for a in candidates if a.qa_approved]
    log.info("%d are qa-approved", len(eligible))

    promoted = failed = 0
    for a in eligible:
        if art.already_promoted(a.name, s.dst_channel):
            log.info("idempotent skip %s (already in %s)", a.name, s.dst_channel)
            continue
        try:
            if s.dry_run:
                log.info("DRY-RUN would promote %s: %s → %s",
                         a.name, s.src_channel, s.dst_channel)
            else:
                art.promote(a.name, s.src_channel, s.dst_channel)
                submit_smoke_job(s.namespace, a.sha, s.smoke_image)
                notify(s.slack_webhook,
                       f"promoted `{a.name}` from {s.src_channel} → {s.dst_channel}")
            promoted += 1
        except Exception:
            log.exception("promotion failed for %s", a.name)
            notify(s.slack_webhook,
                   f"promotion FAILED for `{a.name}`", ok=False)
            failed += 1

    return promoted, failed

CLI entrypoint

pythonsrc/promote_bot/cli.py
from __future__ import annotations
import logging, json, sys, os
from pathlib import Path
import typer
from .config import Settings, load_extra_yaml
from .k8s import load_config as load_k8s_config
from .promoter import reconcile

app = typer.Typer(no_args_is_help=True)
log = logging.getLogger("promote_bot")

def configure_logging():
    h = logging.StreamHandler(sys.stderr)
    h.setFormatter(logging.Formatter(
        '{"ts":"%(asctime)s","lvl":"%(levelname)s","logger":"%(name)s","msg":%(message)s}',
        defaults={"msg": "%s"},
    ))
    # The trick: emit JSON-shaped logs but keep python's % formatting
    logging.basicConfig(level=os.environ.get("LOG_LEVEL", "INFO"), handlers=[h])

@app.command()
def run(
    config_file: Path = typer.Option(None, "--config", help="Optional YAML config"),
    dry_run: bool = typer.Option(False, "--dry-run"),
):
    """Run one reconcile pass and exit."""
    configure_logging()
    s = Settings()
    if config_file:
        s = load_extra_yaml(s, config_file)
    if dry_run:
        s = s.model_copy(update={"dry_run": True})
    load_k8s_config()

    log.info("starting promote_bot src=%s dst=%s dry_run=%s",
             s.src_channel, s.dst_channel, s.dry_run)
    promoted, failed = reconcile(s)
    log.info("done: %d promoted, %d failed", promoted, failed)
    raise typer.Exit(code=0 if failed == 0 else 1)

if __name__ == "__main__":
    app()

pythontests/test_promoter.py
import pytest, responses
from promote_bot.config import Settings
from promote_bot.promoter import reconcile
from unittest.mock import patch

@pytest.fixture
def settings():
    return Settings(
        nexus_url="https://nexus.test",
        nexus_token="t",
        src_channel="dev",
        dst_channel="staging",
        smoke_image="x:1.0",
        namespace="promote",
        dry_run=True,
    )

@responses.activate
def test_reconcile_skips_unapproved(settings):
    responses.add(
        responses.GET,
        "https://nexus.test/api/repositories/dev-local/items",
        json={"items": [{
            "name": "fw-1", "properties": {"sha": "abc", "qa-approved": "false"}}]},
        status=200,
    )
    with patch("promote_bot.promoter.submit_smoke_job") as mock_job:
        promoted, failed = reconcile(settings)
    assert promoted == 0 and failed == 0
    mock_job.assert_not_called()

@responses.activate
def test_reconcile_dry_run_doesnt_promote(settings):
    responses.add(
        responses.GET,
        "https://nexus.test/api/repositories/dev-local/items",
        json={"items": [{
            "name": "fw-1",
            "properties": {"sha": "abc", "qa-approved": "true"}}]},
        status=200,
    )
    responses.add(
        responses.GET,
        "https://nexus.test/api/storage/staging-local/fw-1",
        status=404,
    )
    with patch("promote_bot.promoter.submit_smoke_job") as mock_job:
        promoted, failed = reconcile(settings)
    assert promoted == 1 and failed == 0
    mock_job.assert_not_called()             # dry_run=True

Extensions

  1. Operator-ify it. Replace the CronJob with a Kopf controller that watches for a custom PromotionRequest resource. Users kubectl apply a request; the operator promotes. We covered the pattern in Chapter 12.
  2. Add metrics. Prometheus client emitting promote_total, promote_failures, promote_duration_seconds. Push to a Pushgateway since this is a short-lived Job, or expose /metrics if you switch to a Deployment.
  3. Add a real ledger. Persist promoted SHAs in a Postgres or DynamoDB table for audit. The bot reads on startup and refuses to re-promote anything seen.
  4. Implement rollback. A second CronJob (or CLI subcommand) that demotes from staging based on a list of bad SHAs.
  5. Add a CRD for rules. Today the rule is hardcoded in code. Make it declarative: a PromotionRule CRD with src/dst/label/schedule, and the bot reconciles all rules.
  6. Wire up External Secrets. The token in the Secret manifest is a placeholder. In production, ESO syncs it from Vault.
  7. Argo CD it. Put deploy/ in a config repo, point an Argo CD Application at it, never kubectl apply manually again.

Where to go from here

  • Read the kubernetes-client-python source. The official SDK is auto-generated from OpenAPI — once you know the resource model, the API maps 1:1.
  • Write a Kopf operator. Half a day; you'll come out understanding controllers from the inside.
  • Run kube-prometheus-stack on kind. See your own metrics and the cluster's, locally. Best way to learn what to monitor.
  • Read the Linux kernel's cgroup v2 docs. Resource limits, eviction, and OOM behaviour all bottom out there. Once you've read them, K8s' resource model stops being magic.
  • Build something real. Pipeline glue, CI utilities, deployment helpers. Python + K8s API + a CronJob is a small but immensely productive sweet spot.

You now have all three legs: Python as a comfortable working language, automation patterns that survive contact with reality, and a working mental model of Kubernetes. The combination is unreasonably effective. Go ship something.
