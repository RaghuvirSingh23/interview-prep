Chapter 13 The 50 Questions

Fifty questions you'll be asked across Python, automation, and Kubernetes — interviews, design reviews, on-call investigations. Concise answers; snippets where the right answer is code.

Python (15)

List vs tuple — when to use each?

Tuple for fixed-shape records (return values from functions, dict keys); list for collections you'll grow or mutate. Tuples are hashable, lists aren't. Performance is similar; the real difference is intent.

Difference between is and ==?

is tests identity (same object in memory); == tests equality (same value, via __eq__). Always use == for value comparisons. Use is for None, True, False — those are singletons.

Why is def f(x=[]) a bug?

The default [] is created once, at function-definition time, and shared across all calls that don't pass x. Mutating it leaks state between calls. Use def f(x=None): if x is None: x = [], or field(default_factory=list) in dataclasses.

What's the GIL?

The Global Interpreter Lock — a mutex around the CPython interpreter that allows only one thread to execute Python bytecode at a time. Threads are great for I/O-bound work (network, disk) because the GIL is released during blocking calls. They're useless for CPU-bound work — use multiprocessing or async I/O instead. Python 3.13+ has experimental no-GIL builds.

When do you use asyncio vs threads vs processes?

Async for I/O-bound, fan-out-many tasks (HTTP fan-out, websockets, event loops). Threads for I/O-bound where the libraries are blocking and rewriting them is too much. Processes for CPU-bound work — multiprocessing.Pool or concurrent.futures.ProcessPoolExecutor.

Why __slots__?

Tells Python "this class has exactly these attributes" — saves memory by skipping the per-instance __dict__, and makes attribute access faster. Use for classes you'll instantiate millions of times. Modern alternative: @dataclass(slots=True).

Difference between a generator and an iterator?

An iterator is any object with __iter__ + __next__. A generator is the special case produced by a function with yield — Python writes the iterator boilerplate for you. Generator expressions (x*x for x in xs) are inline generators.

What does @property do?

Turns a method into a read-only attribute. foo.area instead of foo.area(). Pair with a @area.setter if you need writes. Useful for computed values that look like attributes from the outside.

EAFP vs LBYL?

"Easier to ask forgiveness than permission" (try/except) vs "Look before you leap" (if-checks). Pythonic style is EAFP — try the operation, handle the exception. Avoids race conditions: if path.exists(): open(path) can fail if the file's deleted in between.

What's a context manager and how do you write one?

An object usable in with. Two ways: implement __enter__ + __exit__, or decorate a generator function with @contextlib.contextmanager using yield for the boundary.

@contextmanager
def cd(path):
    prev = Path.cwd(); os.chdir(path)
    try: yield path
    finally: os.chdir(prev)
How do you handle CPython's lack of true threading without GIL?

For I/O: threads or asyncio (GIL releases during I/O). For CPU: multiprocessing, or call into native code (NumPy, Polars, Rust extensions like orjson, pydantic-core) which release the GIL. For massively parallel CPU work, ship to a real worker queue (Celery, RQ, Dask) or rewrite hot paths in Rust/C.

What's the difference between copy and deepcopy?

copy.copy(x) creates a new top-level container; nested objects are shared by reference. copy.deepcopy(x) recursively copies everything. Default is shallow, which is usually what you want — deepcopy is expensive and surprising.

Why pin dependencies?

So your environment is reproducible — same code, same deps, same runtime, same behaviour. Without pinning, a transitive dep can release a bad version overnight and break Tuesday's deploy. Lockfiles with hashes (uv, pip-tools) are the right answer.

How do you debug a hanging Python process?

Send it SIGUSR1 if it has a faulthandler. Otherwise: py-spy dump --pid <pid> shows the current stack trace of every thread without stopping the process. Or attach with gdb + the Python helpers. py-spy is the modern winner.

What's __init_subclass__ and when is it useful?

A hook that runs when a subclass is defined. Lets a base class register or validate subclasses without a metaclass. Useful for plugin patterns: every subclass auto-registers in a registry. Cleaner than metaclasses for the 90% case.

Automation (10)

Define idempotency in one sentence.

An operation is idempotent if running it twice has the same effect as running it once.

Why retry with jitter?

Without jitter, simultaneous failures cause clients to retry in lockstep, hammering downstreams at every backoff boundary. Jitter spreads retries randomly, letting servers actually recover.

Why never use shell=True with user-controlled input?

The shell parses the command line — semicolons, pipes, backticks, redirects all execute. filename = "x; rm -rf $HOME" via shell=True runs both. The list form goes straight to execve; the entire argument is opaque data.

How do atomic writes work?

Write to a temp file in the same directory, fsync, then os.replace to the final name. POSIX guarantees rename is atomic; the final file either contains the new data or doesn't exist. Survives crashes, signals, and OOMs without leaving partial files.

How do you prevent two cron runs overlapping?

File lock with fcntl.flock in non-blocking mode (LOCK_NB). Second invocation gets BlockingIOError, exits 0 silently. For multi-host: Redis with SETNX + TTL, or a real lock service.

What's a circuit breaker?

A wrapper that stops calling a downstream after consecutive failures, for a cooldown period. Lets the downstream recover instead of being hammered by retries. Half-open state occasionally lets one request through to test recovery.

Webhook security — minimum checklist?

(1) Verify HMAC signature with hmac.compare_digest. (2) Reject unknown event types. (3) Dedupe by event ID. (4) Reply 200 fast, queue the work. (5) IP allowlist if the sender publishes IPs.

Why log to stderr, not stdout?

Stdout is reserved for program output; mixing logs with output breaks shell pipelines. Stderr is for diagnostics. Conventionally, redirect just stdout (cmd > result.txt) and you still see logs on the terminal.

What does graceful shutdown mean?

Catch SIGTERM, set a "stopping" flag, finish the current logical unit of work (don't interrupt mid-write), flush metrics/logs, exit 0. K8s sends SIGTERM before SIGKILL; honoring it prevents data loss.

Why --dry-run on every state-mutating CLI?

So a typo or misconfig prints what would happen rather than doing it. Saves you from "oh, that wasn't the staging cluster, it was prod". CI can run integration tests in dry-run mode against production credentials and catch problems before they happen.

Kubernetes (20)

What is Kubernetes in one sentence?

A database (etcd) of desired state, plus a set of controllers that reconcile actual state to match.

spec vs status?

spec is what the user wants. status is what controllers have done. You write spec; you read status to see whether the system has caught up.

Pod vs Deployment vs ReplicaSet — relationships?

You write a Deployment. The Deployment controller creates a ReplicaSet matching its template. The ReplicaSet controller creates Pods matching its template. Pods run containers. Update the Deployment template → new ReplicaSet → rolling replacement.

When do I use a StatefulSet vs Deployment?

StatefulSet when each pod needs a stable name, stable network identity, or its own persistent volume — typically databases and stateful brokers. Deployment for everything stateless.

readiness vs liveness probe?

Readiness gates traffic — failing means "remove from Service endpoints, don't kill". Liveness gates restarts — failing means "kill and restart". Different thresholds, often different paths.

Why often skip CPU limits but always set memory limits?

CPU is compressible — exceeding the cap means throttling, which is fine. Cgroup CPU throttling at fractional limits causes severe latency spikes. Memory isn't compressible — exceeding the cap = OOMKill. Cap memory; let CPU stretch.

How do I make ConfigMap changes trigger a rollout?

Annotate the Pod template with a checksum of the ConfigMap content. Helm: checksum/config: {{ include … | sha256sum }}. Plain manifests: compute SHA in your CI and patch in. The annotation change → template hash change → new ReplicaSet → rolling restart.

What's RWO and what does it mean for replicas?

ReadWriteOnce: only one node can attach the volume at a time. A Deployment with replicas > 1 sharing one PVC is broken — second pod fails to attach. Use a StatefulSet with per-pod PVCs, or RWX storage if shared writes are essential.

What does NetworkPolicy do?

Pod-level firewalling. Without one, all pods can reach all pods. With any NetworkPolicy targeting a pod, all other traffic is denied — explicit-allow model. Use a "default-deny-all" baseline plus per-app allow rules.

Why prefer Ingress over LoadBalancer per service?

Cost: cloud LBs are ~$25/mo each. One Ingress fronts many services through one LB. Plus centralised TLS, redirects, rate-limit, auth.

What does kubectl explain pod.spec.containers do?

Prints the OpenAPI documentation for every field of pod.spec.containers, sourced from the live API server. The schema travels with your cluster version. Whenever you forget a field, this is the answer.

Pod's QoS class — how is it determined?

Guaranteed: every container has CPU and memory limits == requests. Burstable: at least one container has requests < limits, or only requests set. BestEffort: no requests or limits anywhere. Eviction order under node pressure: BestEffort → Burstable → Guaranteed.

What's terminationGracePeriodSeconds?

How long kubelet waits between sending SIGTERM and SIGKILL. Default 30s. For graceful drains, set to comfortably more than your shutdown takes (DB connection close, in-flight request finish). Pair with a preStop sleep to give kube-proxy time to drop the pod from EndpointSlice before SIGTERM.

When do I need a sidecar?

When two processes have to share a Pod's lifecycle and (typically) a volume. Classic uses: log shippers, service-mesh proxies (Envoy/Istio), TLS terminators, secret refreshers. K8s 1.29+ has formal sidecar support via initContainers[].restartPolicy: Always, fixing lifecycle ordering.

DaemonSet — when?

"One pod per node" — log forwarders, metrics agents, CSI drivers, kube-proxy. Add tolerations to land on tainted nodes (control-plane, GPU).

CronJob concurrency — what's Forbid?

If the previous Job is still running when the next schedule fires, skip the new one. Use for non-overlapping jobs that mutate shared state. Default Allow can pile up runs if the job runs longer than its schedule interval.

RBAC — Role vs ClusterRole?

Role: namespaced — applies only within one namespace. ClusterRole: cluster-wide — for cluster-level resources (nodes, namespaces) or to be reusable across namespaces. Bind ClusterRoles via RoleBinding to scope them to one namespace.

What's a controller, in one sentence?

A program that watches the API server for resources of some kind and takes actions to make actual state match desired state.

When write an operator?

When your domain has a noun that needs declarative API + non-trivial reconciliation across multiple K8s resources. Don't write one when a Helm chart + a CronJob solves it.

What's GitOps and why?

Git as the source of truth for cluster state; a controller (Argo CD, Flux) reconciles cluster to git. Benefits: full audit log = git log, code review on every change, drift detection, easy rollback. Trade-off: emergency manual fixes have to be either disciplined or temporarily allowed.

Ops & production (5)

My pod is in CrashLoopBackOff. What's the diagnostic order?

(1) kubectl describe pod X — check Events for image-pull issues, resource issues, init-container failures. (2) kubectl logs X --previous — last container's stdout/stderr. (3) kubectl logs X -c <name> if multi-container. (4) kubectl debug -it pod/X --image=busybox --target=name for an interactive shell. (5) Check probes — too aggressive liveness restarts pods that were just slow to start.

Pod is Pending forever. Why?

Most common: no node has enough resources for the pod's requests. kubectl describe pod → Events show "FailedScheduling" with the reason ("Insufficient cpu", "0/3 nodes are available: 3 node(s) had untolerated taint"). Other causes: PVC stuck waiting for a PV, image pull credentials missing, scheduler stuck.

Service has endpoints but pods aren't getting traffic — why?

Likely the EndpointSlice doesn't actually include them. Check kubectl get endpointslice -l kubernetes.io/service-name=mysvc. If empty: readiness probe failing, label mismatch between Pod and Service selector, or pods in wrong namespace. If non-empty but specific pods missing: those pods aren't ready.

My HPA isn't scaling — what to check?

(1) kubectl get hpa — check the TARGETS column. <unknown>/70% means metrics-server can't read pod metrics. (2) Pods need resources.requests.cpu set; HPA computes utilisation against requests. (3) Check metrics-server is installed and healthy. (4) Stabilization window: HPA waits before scaling down to avoid flapping.

How do I cap blast radius for a misbehaving namespace?

Layer: ResourceQuota (caps total CPU/memory/pod count), LimitRange (default + max per pod), NetworkPolicy (deny cross-namespace by default), Pod Security Admission set to restricted, RBAC scoped to the namespace, separate ServiceAccount per workload. The combination means a buggy or hostile namespace can't starve neighbours, escalate privilege, or talk to other apps.

Bonus — ten more that come up

Why use uv over pip?

10-100× faster installs, built-in venv management, replaces pip-tools for lockfiles, single static binary. The 2026 default for new Python projects. Same install commands, much faster.

What's Pydantic v2?

The most-used data validation library in Python. v2 rewrote the core in Rust; ~5–50× faster than v1. Use it for parsing untrusted input, settings management (via pydantic-settings), and FastAPI request/response shapes.

When use threads vs processes vs async in Python?

I/O-bound, lots of concurrency: async (asyncio + httpx). I/O-bound, blocking libraries: threads. CPU-bound: multiprocessing or external workers. Mostly: pick async unless something specifically forces a thread/process.

How does kubectl auth work?

Reads ~/.kube/config for the current context's user, which has either client cert/key, a bearer token, or an exec plugin (aws eks get-token, gke-gcloud-auth-plugin) that produces a token at request time. The API server validates and applies RBAC.

What's a DaemonSet for storage drivers?

CSI drivers run as DaemonSets on every node — they need to handle volume mount/unmount calls from kubelet, which run locally. Same for kube-proxy and CNI agents.

How do you migrate a Deployment to a StatefulSet without downtime?

Hard — they have different naming and Pod identity semantics. Practical approaches: (a) deploy the StatefulSet alongside, switch the Service selector once it's ready, delete the Deployment; (b) for stateful apps, accept a maintenance window because the data needs to be moved into the StatefulSet's PVCs anyway.

What's kubectl rollout undo?

Reverts a Deployment (or DaemonSet, StatefulSet) to its previous ReplicaSet — i.e. previous template. Equivalent to kubectl rollout undo deploy/X --to-revision=N. History limit set by spec.revisionHistoryLimit.

What is HPA stabilisation window?

The minimum interval before a scaling decision is reversed. Without it, replicas would flap up/down on metric noise. Default 5m on scale-down, 0 on scale-up; tune via spec.behavior.

Best way to inject secrets in 2026?

For cloud creds: IRSA (AWS) or Workload Identity (GCP/Azure) — no Secret on disk at all. For everything else: External Secrets Operator pulling from Vault/AWS SM. Plain K8s Secrets are last resort, encrypted at rest, with strict RBAC.

What does kubectl debug do?

Attaches an ephemeral debug container to a running Pod (sharing its network/PID namespace as configured), without modifying the Pod manifest. Lets you bring debugging tools (curl, dig, tcpdump) into a slim production image without baking them in. Critical for "I can't repro it locally" investigations.
