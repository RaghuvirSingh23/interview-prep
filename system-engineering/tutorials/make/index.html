A Deep Dive GNU Make, from first principles.

Most people learn enough Make to copy an existing Makefile and stop. That's a shame — Make is a tiny, beautiful language for describing how files depend on other files, and once you truly understand it you'll use it for years. This tutorial takes you from the first rule to metaprogramming, parallel builds, and the patterns real C projects use.

14 chapters 120+ exercises 50 interview-style questions ~6 hours to read, weeks to internalise

How to use this tutorial

This is a hands-on tutorial. You will learn Make by running it, not by reading about it. Every chapter contains:

  • Concept prose — what the feature is, when to use it, and why it exists.
  • Code examples — every Makefile snippet is copy-pasteable. Tabs are rendered as → so you can see them.
  • Hands-on blocks — terminal sessions you should actually type. The commands and expected output are shown.
  • Pitfalls — the traps I fell into so you don't have to.
  • Exercises — 3–8 per chapter, each with a collapsible solution. Do them. Don't peek.
Before you start

Open a terminal. Create a scratch directory and stay in it for the whole course:

$ mkdir -p ~/learning-make && cd ~/learning-make

Every chapter assumes you're in that directory and may leave files behind. If you want a clean slate, rm -rf * between chapters — or keep them as a reference.

What you will learn

By the end of this tutorial you will:

  • Read any Makefile in the wild and know what it's doing.
  • Write Makefiles that correctly express why things depend on other things, not just how to build them.
  • Use automatic dependency generation (the -MMD -MP trick) so you never forget a header change again.
  • Debug a broken Makefile with --debug, -n, -p, and the $(info …) function.
  • Write non-recursive Makefiles that scale to hundreds of source files — and understand why recursive Make is harmful.
  • Answer, with confidence, every common Make question an interviewer or colleague will ever throw at you.

Prerequisites

  • A Unix-like shell (macOS Terminal, Linux, WSL). Windows native works too but paths differ — prefer WSL if you're on Windows.
  • make installed. Check with make --version. You want GNU Make 4.0 or newer (macOS ships 3.81 which is ancient — install GNU make via brew install make and invoke it as gmake).
  • A working C compiler (gcc or clang) for the C-build chapters.
  • Comfort reading shell commands. You don't need to be a shell wizard, but ls, cat, echo, and redirection should feel natural.
What this tutorial is not

This is not a reference manual. For exhaustive detail, read the official GNU Make manual — it is surprisingly readable, and I'll cite chapters from it throughout. This tutorial is the curriculum the manual wishes it had: a guided tour through every feature you will actually use, with exercises that build the intuition a reference book can't give you.
