Chapter 14 Capstone Project

One last project that uses everything we've covered. Build a small C library called miniset — a generic hash set — plus a CLI that uses it, a test suite, and a release pipeline. By the end you'll have a Makefile you'd be proud to ship.

Goals

  • Non-recursive Makefile (Chapter 12).
  • Separate src/lib, src/bin, tests/, include/ trees.
  • Auto-dependency tracking for headers (Chapter 9).
  • Debug / release / asan configurations (Chapter 8).
  • Parallel-safe (Chapter 10).
  • Self-testing make check.
  • Install + uninstall respecting DESTDIR and prefix.
  • Source tarball + release zip.
  • A make help that prints everything above.

csrc/lib/hash.c
#include "miniset.h"

/* FNV-1a — small, good enough, same license as everything. */
uint32_t miniset_hash(const char *key) {
    uint32_t h = 2166136261u;
    while (*key) { h ^= (unsigned char)*key++; h *= 16777619u; }
    return h;
}
csrc/lib/miniset.c
#include <stdlib.h>
#include <string.h>
#include "miniset.h"

struct entry  { char *key; struct entry *next; };
struct miniset { struct entry **buckets; size_t n, cap; };

static const size_t CAP = 64;

miniset_t *miniset_new(void) {
    miniset_t *s = calloc(1, sizeof *s);
    s->cap = CAP;
    s->buckets = calloc(CAP, sizeof *s->buckets);
    return s;
}

void miniset_free(miniset_t *s) {
    if (!s) return;
    for (size_t i = 0; i < s->cap; i++) {
        struct entry *e = s->buckets[i];
        while (e) { struct entry *n = e->next; free(e->key); free(e); e = n; }
    }
    free(s->buckets); free(s);
}

static struct entry **find(const miniset_t *s, const char *key) {
    size_t i = miniset_hash(key) % s->cap;
    struct entry **p = (struct entry **)&s->buckets[i];
    while (*p && strcmp((*p)->key, key) != 0) p = &(*p)->next;
    return p;
}

int miniset_insert(miniset_t *s, const char *key) {
    struct entry **p = find(s, key);
    if (*p) return 0;
    struct entry *e = malloc(sizeof *e);
    e->key = strdup(key); e->next = NULL;
    *p = e; s->n++;
    return 1;
}

int miniset_contains(const miniset_t *s, const char *key) {
    return *find(s, key) != NULL;
}

int miniset_delete(miniset_t *s, const char *key) {
    struct entry **p = find(s, key);
    if (!*p) return 0;
    struct entry *e = *p;
    *p = e->next;
    free(e->key); free(e);
    s->n--;
    return 1;
}

size_t miniset_size(const miniset_t *s) { return s->n; }
csrc/bin/minisetcli.c
#include <stdio.h>
#include <string.h>
#include "miniset.h"

#ifndef VERSION
#define VERSION "dev"
#endif

int main(int argc, char **argv) {
    miniset_t *s = miniset_new();
    for (int i = 1; i < argc; i++) miniset_insert(s, argv[i]);
    printf("miniset %s: size=%zu\n", VERSION, miniset_size(s));
    miniset_free(s);
    return 0;
}
ctests/test_insert.c

The Makefile

Now the main event. Read this top to bottom; every idiom should be something you recognise by now.

makeMakefile — capstone
# =====================================================================
# miniset — capstone build
# =====================================================================
.DELETE_ON_ERROR:
.SUFFIXES:
MAKEFLAGS += --no-builtin-rules --warn-undefined-variables

SHELL       := /bin/bash
.SHELLFLAGS := -eu -o pipefail -c

# --- project metadata ------------------------------------------------
NAME    := miniset
VERSION != git describe --tags --always --dirty 2>/dev/null || echo dev
LIBNAME := lib$(NAME).a

# --- configuration ---------------------------------------------------
CONFIG  ?= release

CFLAGS_release := -O2 -DNDEBUG
CFLAGS_debug   := -O0 -g
CFLAGS_asan    := -O1 -g -fsanitize=address -fno-omit-frame-pointer
LDFLAGS_asan   := -fsanitize=address

ifeq ($(origin CFLAGS_$(CONFIG)),undefined)
$(error Unknown CONFIG=$(CONFIG). Valid: release debug asan)
endif

# --- tools ------------------------------------------------------------
CC      ?= cc
AR      ?= ar
INSTALL ?= install

# --- flags ------------------------------------------------------------
CPPFLAGS += -Iinclude -DVERSION='"$(VERSION)"'
CFLAGS   += -std=c11 -Wall -Wextra -Wpedantic
CFLAGS   += -MMD -MP
CFLAGS   += $(CFLAGS_$(CONFIG))
LDFLAGS  += $(LDFLAGS_$(CONFIG))
LDLIBS   +=

# --- layout -----------------------------------------------------------
BLD       := build/$(CONFIG)

LIB_SRC   := $(wildcard src/lib/*.c)
LIB_OBJ   := $(patsubst src/lib/%.c,$(BLD)/lib/%.o,$(LIB_SRC))
LIB       := $(BLD)/$(LIBNAME)

BIN_SRC   := $(wildcard src/bin/*.c)
BIN_OBJ   := $(patsubst src/bin/%.c,$(BLD)/bin/%.o,$(BIN_SRC))
BIN       := $(BLD)/$(NAME)

TEST_SRC  := $(wildcard tests/*.c)
TEST_BIN  := $(patsubst tests/%.c,$(BLD)/tests/%,$(TEST_SRC))

DEP       := $(LIB_OBJ:.o=.d) $(BIN_OBJ:.o=.d) $(TEST_BIN:=.d)

# --- default / help ---------------------------------------------------
.PHONY: all help
.DEFAULT_GOAL := all
all: $(BIN)                                                ## build the CLI

help:                                                      ## show this help
	@awk 'BEGIN {FS=":.*##"} /^[a-zA-Z_-]+:.*##/ { \
	      printf "  %-18s %s\n", $$1, $$2 }' $(MAKEFILE_LIST)
	@echo ""
	@echo "Variables:"
	@echo "  CONFIG=release|debug|asan  (current: $(CONFIG))"
	@echo "  V=1                        verbose"
	@echo "  prefix=/usr/local          install prefix"
	@echo ""
	@echo "Version:  $(VERSION)"

# --- quiet vs verbose -------------------------------------------------
Q := $(if $(V),,@)
define log
	@printf '  \033[1;33m%-4s\033[0m %s\n' '$(1)' '$(2)'
endef

# --- library ----------------------------------------------------------
$(LIB): $(LIB_OBJ)
	$(call log,AR,$@)
	$(Q)$(AR) crs $@ $^

$(BLD)/lib/%.o: src/lib/%.c | $(BLD)/lib
	$(call log,CC,$<)
	$(Q)$(CC) $(CPPFLAGS) $(CFLAGS) -c $< -o $@

# --- binary -----------------------------------------------------------
$(BIN): $(BIN_OBJ) $(LIB)
	$(call log,LD,$@)
	$(Q)$(CC) $(LDFLAGS) $(BIN_OBJ) $(LIB) $(LDLIBS) -o $@

$(BLD)/bin/%.o: src/bin/%.c | $(BLD)/bin
	$(call log,CC,$<)
	$(Q)$(CC) $(CPPFLAGS) $(CFLAGS) -c $< -o $@

# --- tests ------------------------------------------------------------
.PHONY: check
check: $(TEST_BIN)                                         ## build & run tests
	@pass=0; fail=0; \
	 for t in $^; do \
	   if "./$$t"; then pass=$$((pass+1)); \
	   else fail=$$((fail+1)); fi; \
	 done; \
	 echo ""; \
	 printf '  \033[1;32m%d passed\033[0m  \033[1;31m%d failed\033[0m\n' $$pass $$fail; \
	 [ $$fail -eq 0 ]

$(BLD)/tests/%: tests/%.c $(LIB) | $(BLD)/tests
	$(call log,TST,$<)
	$(Q)$(CC) $(CPPFLAGS) $(CFLAGS) $< $(LIB) -o $@

# --- install ----------------------------------------------------------
prefix  ?= /usr/local
bindir  := $(prefix)/bin
libdir  := $(prefix)/lib
incdir  := $(prefix)/include
mandir  := $(prefix)/share/man/man1
DESTDIR ?=

.PHONY: install uninstall
install: $(BIN) $(LIB)                                     ## install to $(prefix)
	$(INSTALL) -d $(DESTDIR)$(bindir) $(DESTDIR)$(libdir) \
	             $(DESTDIR)$(incdir) $(DESTDIR)$(mandir)
	$(INSTALL) -m 755 $(BIN)            $(DESTDIR)$(bindir)/
	$(INSTALL) -m 644 $(LIB)            $(DESTDIR)$(libdir)/
	$(INSTALL) -m 644 include/miniset.h $(DESTDIR)$(incdir)/
	$(INSTALL) -m 644 docs/$(NAME).1    $(DESTDIR)$(mandir)/

uninstall:                                                 ## remove installed files
	rm -f $(DESTDIR)$(bindir)/$(NAME) \
	      $(DESTDIR)$(libdir)/$(LIBNAME) \
	      $(DESTDIR)$(incdir)/miniset.h \
	      $(DESTDIR)$(mandir)/$(NAME).1

# --- release ---------------------------------------------------------
RELEASE := $(NAME)-$(VERSION)

.PHONY: dist
dist: $(RELEASE).tar.gz                                    ## source tarball

$(RELEASE).tar.gz:
	git archive --format=tar.gz --prefix=$(RELEASE)/ -o $@ HEAD

# --- directory creation -----------------------------------------------
$(BLD)/lib $(BLD)/bin $(BLD)/tests:
	@mkdir -p $@

# --- dependency files -------------------------------------------------
-include $(DEP)

# --- cleanup ----------------------------------------------------------
.PHONY: clean distclean
clean:                                                     ## remove build/
	rm -rf build

distclean: clean                                           ## also remove tarballs
	rm -f *.tar.gz

That's ~130 lines of Makefile. It builds a library, a CLI, and three tests, in three configurations, with per-header dependency tracking, pretty output, install/uninstall, release tarballs, and a help screen. I want you to feel that this is manageable — every line is something you've seen.

Notice: changing CONFIG builds into a separate build/<config>/ tree, so the release and asan builds coexist. Auto-deps live in their respective build/*/lib/*.d. Parallelism scales across the whole graph.

Suggested extensions

  1. Shared library. Add a rule for build/release/libminiset.so (using -fPIC -shared) and an SO target in the default goals.
  2. Coverage. Add CONFIG=coverage with --coverage, plus a make coverage target that runs tests and emits an HTML report via lcov.
  3. Fuzzing. Add CONFIG=fuzz with -fsanitize=fuzzer,address and a fuzz/ directory for libFuzzer entry points.
  4. Benchmark. Add a make bench target that compiles and runs a benchmark, dumping timings.
  5. pkg-config file. Generate and install a miniset.pc so downstream users can pkg-config --cflags miniset.
  6. CI configuration. Write a .github/workflows/ci.yml that runs make -j check in all three configurations.

Each of these is a 10-30 line extension to the Makefile. Try one.

EX 14.2 medium Add the shared library

Extend the Makefile to also produce build/$(CONFIG)/libminiset.so (or .dylib on macOS). Add an SO variable and make all depend on it. The library's object files should use -fPIC.

Show solution 
LIB_OBJ_PIC := $(patsubst src/lib/%.c,$(BLD)/lib/%.pic.o,$(LIB_SRC))
SO := $(BLD)/$(LIBNAME:.a=.so)

ifeq ($(shell uname -s),Darwin)
  SO := $(BLD)/$(LIBNAME:.a=.dylib)
  SOFLAGS := -dynamiclib -install_name @rpath/$(notdir $(SO))
else
  SOFLAGS := -shared -Wl,-soname,$(notdir $(SO))
endif

all: $(BIN) $(SO)

$(SO): $(LIB_OBJ_PIC)
	$(call log,LD,$@)
	$(Q)$(CC) $(LDFLAGS) $(SOFLAGS) $^ -o $@

$(BLD)/lib/%.pic.o: src/lib/%.c | $(BLD)/lib
	$(call log,CC,$<)
	$(Q)$(CC) -fPIC $(CPPFLAGS) $(CFLAGS) -c $< -o $@

Note: we compile library sources twice — once as .o for the static lib, once as .pic.o for the shared. Wasteful for small libs; for larger ones, you'd commit to one or the other.

EX 14.3 hard Wire in pkg-config

Generate a miniset.pc from a template, and install it to $(libdir)/pkgconfig/. Use sed or envsubst for the substitution.

Show solution

Template:

pcminiset.pc.in
prefix=@prefix@
exec_prefix=${prefix}
libdir=${exec_prefix}/lib
includedir=${prefix}/include

Name: miniset
Description: Minimal hash set
Version: @version@
Libs: -L${libdir} -lminiset
Cflags: -I${includedir}

Makefile additions:

PC := $(BLD)/miniset.pc

$(PC): miniset.pc.in | $(BLD)
	$(call log,GEN,$@)
	$(Q)sed -e 's|@prefix@|$(prefix)|g' \
	        -e 's|@version@|$(VERSION)|g' $< > $@

install: $(PC)
	$(INSTALL) -d $(DESTDIR)$(libdir)/pkgconfig
	$(INSTALL) -m 644 $(PC) $(DESTDIR)$(libdir)/pkgconfig/

Don't forget to add $(PC) to the cleanup and to all. Test with pkg-config --cflags miniset after install.

EX 14.4 hard CI matrix

Write a .github/workflows/ci.yml that runs make -j check for each CONFIG in [release, debug, asan], plus a lint job using clang-tidy.

Show solution
yaml.github/workflows/ci.yml
name: ci
on: [push, pull_request]
jobs:
  build-test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        config: [release, debug, asan]
    steps:
      - uses: actions/checkout@v4
      - run: sudo apt-get install -y build-essential
      - run: make CONFIG=${{ matrix.config }} -j $(nproc) check

  lint:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: sudo apt-get install -y clang-tidy
      - run: |
          clang-tidy --quiet \
            $(find src include -name '*.[ch]') \
            -- -Iinclude -std=c11

No Makefile changes — the CI calls make CONFIG=... with the variables already supported. That's the point of a clean build system.

EX 14.5 hard Flag-change detection

Remember the "compile-flag change" problem? When CFLAGS changes, Make doesn't rebuild because source files aren't newer. Implement a build/$(CONFIG)/.flags stamp that triggers a full rebuild when any flag changes.

Show solution 
FLAG_STAMP := $(BLD)/.flags

$(shell mkdir -p $(BLD); \
        new='$(CC) $(CPPFLAGS) $(CFLAGS) $(LDFLAGS)'; \
        old="$$(cat $(FLAG_STAMP) 2>/dev/null)"; \
        [ "$$new" = "$$old" ] || printf '%s' "$$new" > $(FLAG_STAMP))

$(LIB_OBJ) $(BIN_OBJ): $(FLAG_STAMP)

Every .o now depends on the flag-stamp, which is rewritten only when flags change. Switch from CONFIG=release to CONFIG=debug: the stamp changes (different flags), every .o is older than the stamp, full rebuild.

In practice we dodge this by using per-config build/ subdirectories, which is cheaper. But for a project without that split, the flag stamp is worth having.

Where to go from here

You now know more about Make than probably 95% of developers who use it. A few paths from here:

  • Real projects. Volunteer to overhaul a gnarly Makefile in a project you care about. The concepts transfer.
  • Ninja. Read the Ninja manual. It's Make's "modern cousin" — same mental model, different syntax, faster. You'll read it in an hour.
  • The GNU Make manual. Now go read the manual cover to cover. After this tutorial, it'll be a breeze — and you'll pick up edge cases and quirks (hello, $(guile …)).
  • Other build tools. Meson, CMake, Bazel, Buck2, Nix — each one is easier with Make as a mental anchor.
  • Read someone else's Makefile. Clone the Linux kernel. Open Makefile. Read until confused. Figure out what's happening. Repeat. It will humble you, and it will make you better.

Make is 50 years old. It's older than most of the people using it. And yet for the next 50 years, whenever someone needs to turn source files into artefacts, make will still be the first tool they try. You're part of that lineage now. Go build something.
