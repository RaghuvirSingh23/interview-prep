A Deep Dive Python, automation, Docker, Kubernetes — for people who already know how to code.

Four topics that ride together in any modern infra-adjacent role: Python as glue, automation as discipline, Docker as the runtime, Kubernetes as the substrate. The Python part is a refresher (you said you know it), pointed at the idioms you'll use in build/CI/automation work — not a "learn Python" walk. Then a deep dive into the patterns, containers, and the cluster.

17 chapters 4 domains 95+ exercises 60 interview Qs

How this is organised

  • Chapters 1–6 — Python & automation. Fast refresher of idiomatic Python, then the standard library you actually use (pathlib, subprocess, requests, logging), data formats, CLI building, and the patterns that make automation reliable (idempotency, retries, locks).
  • Chapters 7–8 — Docker. Image model, layers, Dockerfile, networking, volumes, registries; then the production track — multi-stage, BuildKit cache, distroless, security hardening, signing, scanning, and the bridge to K8s.
  • Chapters 9–14 — Kubernetes. Mental model, core resources, workload types, networking and storage, production patterns (probes, RBAC, HPA), and the ecosystem (Helm, GitOps, operators).
  • Chapter 15 — Jenkins on Kubernetes. Where the two worlds meet: controller in-cluster via Helm, ephemeral agent Pods via the Kubernetes plugin, in-cluster image builds with Kaniko/BuildKit, JCasC, deploying from Jenkins to K8s, and the modern Jenkins-plus-Argo-CD split.
  • Chapter 16 — The 50 Questions. Interview-style Qs across all four.
  • Chapter 17 — Capstone. A Python tool that talks to Kubernetes — a small artifact-promotion controller, packaged in a Docker image, running as a CronJob inside the cluster.
Prerequisites
  • Comfortable Python (3.10+). If you've written a couple thousand lines, you're set.
  • Shell & git basics.
  • Docker installed locally.
  • A local Kubernetes for the K8s chapters: kind, minikube, k3d, or Docker Desktop's built-in. We'll use kind in examples.
  • A managed cluster (GKE/EKS/AKS) is welcome but not required.
