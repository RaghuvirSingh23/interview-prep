Chapter 02 Python Toolbox

The standard library that powers automation: pathlib, subprocess, contextlib, tempfile, shutil, os.environ, logging. After this chapter you should never reach for os.path.join or naked os.system again.

pathlib — paths as objects

from pathlib import Path

p = Path('/var/cache/builds')

# Joining
out = p / 'firmware' / 'v1.0.0' / 'image.img'
# /var/cache/builds/firmware/v1.0.0/image.img

# Inspecting
out.exists(), out.is_file(), out.is_dir()
out.suffix, out.stem, out.name, out.parent
# '.img'  'image'  'image.img'  Path('/var/cache/builds/firmware/v1.0.0')

# Reading / writing
text  = out.with_suffix('.manifest').read_text()
data  = out.read_bytes()
out.write_text("hello", encoding="utf-8")
out.write_bytes(b"\x00\x01")

# Listing
for child in p.iterdir():
    print(child.name)

# Globbing
for img in p.rglob('*.img'):              # recursive
    print(img.relative_to(p))

# Creating
(p / 'staging').mkdir(parents=True, exist_ok=True)

# Removing
(p / 'tmp.txt').unlink(missing_ok=True)   # ignore-if-absent
(p / 'old').rmdir()                        # empty dir only

Stop using os.path.join, os.path.exists, os.path.basename. They're string-shuffling APIs from the 90s.

subprocess — shelling out without footguns

Three idioms cover 95% of usage. Memorise them.

1 · "Run, raise on failure" — the default

import subprocess

subprocess.run(
    ["bitbake", "-c", "build", "core-image-base"],
    check=True,                           # raise CalledProcessError on non-zero
    cwd="/work/yocto",
)

Always pass a list, never a string. A string requires shell=True which opens you to injection if any value is user-controlled. List form goes straight to execve — no shell parsing.

2 · "Run and capture output"

r = subprocess.run(
    ["git", "rev-parse", "HEAD"],
    capture_output=True, text=True, check=True,
)
sha = r.stdout.strip()

capture_output=True is shorthand for stdout=PIPE, stderr=PIPE. text=True decodes as UTF-8 (otherwise you get bytes).

3 · "Stream output as it runs"

with subprocess.Popen(
    ["make", "-j8"],
    stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
    text=True, bufsize=1,
) as proc:
    for line in proc.stdout:
        log.info("[make] %s", line.rstrip())
    rc = proc.wait()
    if rc != 0:
        raise subprocess.CalledProcessError(rc, proc.args)

Use this when builds take minutes and you need real-time logs. bufsize=1 means line-buffered.

Never use shell=True with user-controlled strings
# BAD — if filename is "x; rm -rf /", it runs
subprocess.run(f"cat {filename}", shell=True)

# GOOD
subprocess.run(["cat", filename])

If you genuinely need shell features (pipes, expansion), shell=True is OK with hardcoded strings, but quote any variables with shlex.quote(value).

Useful options

Environment variables

import os

# Read
home = os.environ['HOME']               # raises KeyError if missing
home = os.environ.get('HOME', '/tmp')   # default if missing

# Required, fail loud
def required(name: str) -> str:
    val = os.environ.get(name)
    if not val:
        raise SystemExit(f"required env var missing: {name}")
    return val

NEXUS_URL = required("NEXUS_URL")

For booleans:

def env_bool(name: str, default: bool = False) -> bool:
    raw = os.environ.get(name)
    if raw is None:
        return default
    return raw.lower() in ("1", "true", "yes", "on")

DEBUG = env_bool("DEBUG")

Don't roll a fancy config system for one-off scripts. For real projects, use pydantic-settings or python-decouple.

tempfile — clean temp dirs

import tempfile
from pathlib import Path

# As a context manager — auto-cleanup
with tempfile.TemporaryDirectory() as tmp:
    work = Path(tmp)
    (work / 'input.txt').write_text(payload)
    subprocess.run(["./process", str(work / 'input.txt')], check=True)
    out = (work / 'output.bin').read_bytes()
# tmp is gone here, even if subprocess raised

# Named temp file
with tempfile.NamedTemporaryFile(mode='w', suffix='.json', delete=False) as f:
    json.dump(data, f)
    f.flush()
    config_path = f.name
# careful: with delete=False you must clean up yourself

Rule: prefer TemporaryDirectory + your own files inside it. The auto-cleanup is iron-clad — you never leak temp data, even on a crash.

Atomic writes

Naive: writing directly to a file leaves a half-written file if the process crashes mid-write. Atomic pattern: write to a temp file in the same directory, then rename — POSIX guarantees that's atomic.

from pathlib import Path
import os, tempfile, json

def write_json_atomic(path: Path, data: dict) -> None:
    """Write data as JSON to path, atomically."""
    tmp = tempfile.NamedTemporaryFile(
        mode='w', encoding='utf-8',
        dir=path.parent, prefix=path.name + '.', suffix='.tmp',
        delete=False,
    )
    try:
        json.dump(data, tmp, indent=2, sort_keys=True)
        tmp.flush()
        os.fsync(tmp.fileno())              # write to disk, not just OS cache
        tmp.close()
        os.replace(tmp.name, path)          # atomic on Linux/macOS, also on Windows
    except Exception:
        Path(tmp.name).unlink(missing_ok=True)
        raise

Use this for any "important" file: state, manifests, configs. Pair with fsync on the directory if durability across power loss matters.

hashlib — checksums

import hashlib
from pathlib import Path

def sha256_of(path: Path, chunk: int = 1 << 20) -> str:
    h = hashlib.sha256()
    with path.open('rb') as f:
        while data := f.read(chunk):
            h.update(data)
    return h.hexdigest()

print(sha256_of(Path('image.img')))

Note := walrus in the read loop — assign and test in one expression. Streaming, so it works on multi-GB files.

json — and its quirks

import json
from pathlib import Path

# Read

# Write

# Pretty-print to stdout

default=str handles types JSON doesn't know about (datetime, Path, set) by str-ing them. Useful for logs; for real serialisation, write a custom encoder.

Logging — production-ready setup

import logging, logging.config, sys, os

def configure_logging(level: str = "INFO") -> None:
    logging.config.dictConfig({
        "version": 1,
        "disable_existing_loggers": False,
        "formatters": {
            "human": {
                "format": "%(asctime)s %(levelname)-7s %(name)s | %(message)s",
            },
            "json": {
                "()": "pythonjsonlogger.jsonlogger.JsonFormatter",
                "format": "%(asctime)s %(levelname)s %(name)s %(message)s",
            },
        },
        "handlers": {
            "stderr": {
                "class": "logging.StreamHandler",
                "stream": sys.stderr,
                "formatter": "json" if os.environ.get("LOG_JSON") else "human",
                "level": level,
            }
        },
        "root": {
            "handlers": ["stderr"],
            "level": level,
        },
    })

if __name__ == "__main__":
    configure_logging(os.environ.get("LOG_LEVEL", "INFO"))
    log = logging.getLogger(__name__)
    log.info("starting", extra={"sha": "3f2a1c0", "channel": "dev"})

Always log to stderr. Stdout is reserved for program output; mixing logs and outputs is a classic shell-pipeline trap.

Hands-on: a build wrapper

Hands-on · Yocto build wrapper in 60 lines

A Python script that wraps a long-running build, captures logs, writes a manifest atomically. The kind of thing you'll write a hundred times.

pythonscripts/run_build.py
#!/usr/bin/env python3
"""Run a Yocto build, capture logs, emit a manifest.json."""
from __future__ import annotations
import argparse, hashlib, json, logging, os, subprocess, sys, time
from contextlib import contextmanager
from dataclasses import dataclass, asdict
from datetime import datetime, timezone
from pathlib import Path

log = logging.getLogger("run_build")

@dataclass
class Manifest:
    sha:        str
    machine:    str
    started_at: str
    duration_s: float
    success:    bool
    image_path: str | None
    image_sha:  str | None

def sha256_of(path: Path, chunk: int = 1 << 20) -> str:
    h = hashlib.sha256()
    with path.open('rb') as f:
        while data := f.read(chunk):
            h.update(data)
    return h.hexdigest()

def write_atomic(path: Path, text: str) -> None:
    tmp = path.with_suffix(path.suffix + '.tmp')
    tmp.write_text(text, encoding='utf-8')
    os.replace(tmp, path)

@contextmanager
def timed(label: str):
    t0 = time.monotonic()
    try:
        yield
    finally:
        log.info("%s took %.1fs", label, time.monotonic() - t0)

def run_build(machine: str, build_dir: Path) -> Path:
    build_dir.mkdir(parents=True, exist_ok=True)
    env = {**os.environ, "MACHINE": machine}
    with timed(f"bitbake {machine}"):
        with subprocess.Popen(
            ["bitbake", "core-image-base"],
            cwd=build_dir, env=env, text=True, bufsize=1,
            stdout=subprocess.PIPE, stderr=subprocess.STDOUT,
        ) as proc:
            for line in proc.stdout:
                log.info("[bb] %s", line.rstrip())
            rc = proc.wait()
            if rc != 0:
                raise subprocess.CalledProcessError(rc, proc.args)
    image = build_dir / "tmp" / "deploy" / "images" / machine / "core-image-base.wic"
    if not image.exists():
        raise FileNotFoundError(f"image missing: {image}")
    return image

def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--machine", required=True)
    ap.add_argument("--build-dir", type=Path, default=Path("build"))
    ap.add_argument("--manifest", type=Path, default=Path("manifest.json"))
    args = ap.parse_args()

    logging.basicConfig(level=logging.INFO,
                        format="%(asctime)s %(levelname)-5s | %(message)s")

    sha = subprocess.run(
        ["git", "rev-parse", "HEAD"], capture_output=True, text=True, check=True
    ).stdout.strip()

    started = datetime.now(timezone.utc).isoformat()
    t0 = time.monotonic()
    success, image, image_sha = False, None, None
    try:
        img_path = run_build(args.machine, args.build_dir)
        image, image_sha = str(img_path), sha256_of(img_path)
        success = True
    except Exception:
        log.exception("build failed")

    m = Manifest(
        sha=sha, machine=args.machine, started_at=started,
        duration_s=round(time.monotonic() - t0, 2),
        success=success, image_path=image, image_sha=image_sha,
    )
    write_atomic(args.manifest, json.dumps(asdict(m), indent=2))
    return 0 if success else 1

if __name__ == "__main__":
    raise SystemExit(main())

Read it. Notice every block we covered: subprocess streaming, atomic write, hashing, env extension, dataclass for the record, exception logging, monotonic timing, exit codes.

EX 2.5 hard Cleanup with TemporaryDirectory

Write a script that downloads a tarball into a temp dir, extracts it, runs ./configure && make, and copies the resulting binary to /usr/local/bin. The temp dir must be cleaned up no matter what.

Show solution 
import subprocess, shutil, tempfile, urllib.request
from pathlib import Path

URL = "https://example.com/tool-1.0.tar.gz"
DEST = Path("/usr/local/bin/tool")

with tempfile.TemporaryDirectory() as tmp:
    work = Path(tmp)
    archive = work / "tool.tar.gz"

    urllib.request.urlretrieve(URL, archive)
    shutil.unpack_archive(archive, work)

    src = next(work.glob("tool-*"))                # extracted dir
    subprocess.run(["./configure"], cwd=src, check=True)
    subprocess.run(["make", "-j4"], cwd=src, check=True)

    binary = src / "tool"
    shutil.copy2(binary, DEST)
    DEST.chmod(0o755)
# work is removed automatically

If anything raises, the with still cleans up. No leaks even on Ctrl-C (Python translates SIGINT to KeyboardInterrupt, which still triggers __exit__).

EX 2.6 hard Why no shell=True?

Show, with a tiny example, exactly how subprocess.run(f"cat {filename}", shell=True) can be exploited. Then show the safe equivalent.

Show solution 
# Attacker sets:
filename = "/etc/passwd; rm -rf $HOME"

# Exploitable
subprocess.run(f"cat {filename}", shell=True)
# shell parses: cat /etc/passwd ; rm -rf $HOME
# both commands run.

# Safe
subprocess.run(["cat", filename])
# execve directly; the entire string is one argv[1]
# `cat` reports "no such file: /etc/passwd; rm -rf $HOME"

The list form treats filename as opaque data, never as code. Every CLI vulnerability in Python automation has the same root cause.

Recap

  • pathlib.Path for everything path-shaped. Stop using os.path.
  • subprocess.run(args_list, check=True) as the default. Never shell=True with untrusted input.
  • Stream subprocess output via Popen for long-running commands.
  • Atomic writes: temp file in same dir + fsync + os.replace.
  • tempfile.TemporaryDirectory() as a context manager — no leaks.
  • shutil for copy/move/archive operations.
  • hashlib with chunked reads for big files.
  • logging goes to stderr. print is for program output only.
