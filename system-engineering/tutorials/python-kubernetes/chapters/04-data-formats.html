Chapter 04 Data Formats

JSON, YAML, TOML, CSV, and the quiet middle layer between "raw bytes" and "Python objects": schemas. By the end you'll know when to reach for which format and how to validate untrusted input without hand-rolled if/else trees.

Pick the right format

FormatUse forAvoid for
JSONAPI payloads, machine-to-machine, anything you'll diffHuman-edited config (no comments)
YAMLHuman-edited config (K8s, CI), supports comments & anchorsMachine-to-machine (parser surprises)
TOMLTool config (pyproject.toml, Cargo), simple flat-ishDeeply nested data
CSV/TSVTabular logs, exports, spreadsheetsAnything with structure
JSONLStreaming logs, append-only event dataAnything you need to update in place
Protobuf / MessagePackHot-path RPC, binary efficiencyHuman inspection

Heuristic: humans read it → YAML or TOML. Machines exchange it → JSON. Tabular and stream-friendly → CSV/JSONL. Need every byte → binary.

JSON

import json
from pathlib import Path

# Parse
data = json.loads('{"name": "fw", "version": "1.0"}')
data = json.loads(Path('manifest.json').read_text())

# Emit
text = json.dumps(data, indent=2, sort_keys=True)
Path('out.json').write_text(text)

# Stream — preferred for large arrays
with open('events.json') as f:
    data = json.load(f)
with open('out.json', 'w') as f:
    json.dump(data, f, indent=2)

Common gotchas

  • JSON has no comments. Stop trying. If you need them, use YAML or JSONC (a JSON-with-comments superset many tools accept) or a sidecar file.
  • NaN and Infinity aren't real JSON but json.dumps will emit them by default. Pass allow_nan=False to be strict — strict JSON parsers (browsers) will reject them.
  • Non-string dict keys get coerced to strings: json.dumps({1: "a"}) == '{"1": "a"}'. Round-trip is lossy.
  • Datetime, Path, set, bytes, Decimal aren't natively serialisable. Provide default= or use a custom encoder.

Custom encoder for awkward types

import json
from datetime import datetime, date
from pathlib import Path
from decimal import Decimal

class SmartEncoder(json.JSONEncoder):
    def default(self, o):
        if isinstance(o, (datetime, date)): return o.isoformat()
        if isinstance(o, Path):              return str(o)
        if isinstance(o, set):               return sorted(o)
        if isinstance(o, Decimal):           return str(o)
        return super().default(o)

text = json.dumps(record, cls=SmartEncoder, indent=2)

YAML

import yaml                              # `pip install pyyaml`
from pathlib import Path

data = yaml.safe_load(Path('config.yaml').read_text())

text = yaml.safe_dump(data, sort_keys=False, indent=2)
Path('out.yaml').write_text(text)
Always safe_load — never load

yaml.load can instantiate arbitrary Python objects from YAML tags (!!python/object/apply:os.system) — turning a config file into remote-code-execution. Use yaml.safe_load always; it produces only basic types (dict, list, str, int, float, bool, None). PyYAML even prints a warning the first time you call the unsafe one.

Round-trip preservation: ruamel.yaml

PyYAML's safe_load + safe_dump loses comments and re-orders keys. When you need to edit a YAML file in place — say, bump a version in values.yaml — use ruamel.yaml:

from ruamel.yaml import YAML

yaml = YAML()
yaml.preserve_quotes = True
yaml.indent(mapping=2, sequence=4, offset=2)

with open('values.yaml') as f:
    data = yaml.load(f)

data['image']['tag'] = 'v1.2.3'

with open('values.yaml', 'w') as f:
    yaml.dump(data, f)

Comments, ordering, and quoting style survive the round-trip. Critical for files committed to git that humans also edit.

YAML quirks worth knowing

  • Norway problem. NO, YES, ON, OFF are booleans in YAML 1.1. country: NO becomes False. PyYAML follows YAML 1.1 by default. Quote strings that look booleanish: country: "NO". YAML 1.2 fixed this; ruamel.yaml with typ='safe' uses 1.2.
  • Anchors and merges. &name defines, *name references, <<: *name merges. Useful for DRY in config; awkward when more than one level deep.
  • Multiline strings. | preserves newlines, > folds to spaces. Strip-control: |- strips trailing newline, |+ keeps all.
  • Implicit types bite. version: 1.10 parses as the float 1.1. Always quote version strings.
# Anchor/merge example
defaults: &defaults
  retries: 3
  timeout: 30

prod:
  <<: *defaults
  url: https://api.example.com

staging:
  <<: *defaults
  url: https://staging.example.com
  retries: 5             # override the merged default

TOML

The friendly cousin of INI, with proper types and nesting. pyproject.toml made it ubiquitous in the Python world.

import tomllib                            # std-lib in 3.11+
from pathlib import Path

# Read
data = tomllib.loads(Path('pyproject.toml').read_text())
print(data['project']['name'])

# Write — std-lib has no writer (yet); use tomli-w
import tomli_w
Path('out.toml').write_text(tomli_w.dumps({"project": {"name": "myapp"}}))

TOML's strengths: comments are first-class, dates and durations are typed, structure is unambiguous. Weakness: deeply nested data is awkward (lots of [a.b.c] table headers).

CSV

import csv
from pathlib import Path

# Read (use DictReader — header-aware)
with open('events.csv', newline='') as f:
    for row in csv.DictReader(f):
        print(row['timestamp'], row['event'])

# Write
rows = [
    {'sha': '3f2a1c0', 'machine': 'imx8',  'success': True},
    {'sha': '8b3d291', 'machine': 'rpi4',  'success': False},
]
with open('builds.csv', 'w', newline='') as f:
    w = csv.DictWriter(f, fieldnames=rows[0].keys())
    w.writeheader()
    w.writerows(rows)

Two iron rules:

  • Open with newline=''. Without it, csv duplicates line endings on Windows.
  • For anything serious, use pandas or polars. Quoting, escaping, and dialects (Excel vs Unix) are full of edge cases.

JSONL — one JSON per line

The "everyone loves it for streaming" format:

# Read
def read_jsonl(path):
    with open(path) as f:
        for line in f:
            line = line.strip()
            if line:
                yield json.loads(line)

# Write
def write_jsonl(path, records):
    with open(path, 'w') as f:
        for r in records:
            f.write(json.dumps(r, separators=(',', ':')))
            f.write('\n')

Append-friendly, line-tool-friendly (grep, jq), constant memory. Used heavily for log files, ML datasets, event streams.

Schemas — validate untrusted input

Hand-rolling if "field" not in data: … trees doesn't scale and misses errors. Three good options.

1 · Pydantic v2 — the modern default

from pydantic import BaseModel, Field, field_validator
from datetime import datetime
from typing import Literal

class Manifest(BaseModel):
    sha:        str           = Field(..., pattern=r'^[0-9a-f]{40}$')
    machine:    Literal['imx8', 'rpi4', 'qemu']
    started_at: datetime
    duration_s: float         = Field(..., ge=0)
    success:    bool
    artifacts:  list[str]     = []

    @field_validator('artifacts')
    @classmethod
    def no_dupes(cls, v):
        if len(set(v)) != len(v):
            raise ValueError('artifacts contains duplicates')
        return v

# Parse + validate
m = Manifest.model_validate(json.loads(Path('manifest.json').read_text()))
print(m.sha, m.duration_s)

# Emit JSON
Path('out.json').write_text(m.model_dump_json(indent=2))

What you get: type coercion (string ISO dates → datetime), regex / range validation, custom validators, automatic JSON Schema, structured errors. Fast (Pydantic v2 is Rust-backed) and well-known across the ecosystem.

2 · dataclasses-json or msgspec — leaner

msgspec is the speed king for high-volume parsing. dataclasses-json sticks closer to stdlib idioms. Both are fine for cases where Pydantic is overkill.

3 · jsonschema — when the schema is the contract

Use when you're consuming someone else's published JSON Schema, or when you want the schema in a separate .json file checked into git for non-Python consumers:

import jsonschema
from pathlib import Path

schema = json.loads(Path('manifest.schema.json').read_text())
data   = json.loads(Path('manifest.json').read_text())

jsonschema.validate(data, schema)  # raises ValidationError if invalid

Config-loader pattern

Goal: load user-edited YAML, validate it, present a typed object to the rest of the program. Pydantic does the heavy lifting:

from pydantic import BaseModel, Field
from pathlib import Path
import yaml

class RegistryConfig(BaseModel):
    url:   str
    user:  str
    token: str = Field(..., min_length=8)

class AppConfig(BaseModel):
    name:     str
    channels: list[str] = ['dev', 'staging', 'release']
    registry: RegistryConfig
    debug:    bool = False

def load_config(path: Path) -> AppConfig:
    raw = yaml.safe_load(path.read_text())
    return AppConfig.model_validate(raw)

cfg = load_config(Path('app.yaml'))
print(cfg.registry.url)

One source of truth for both structure and defaults. Misspelled keys, wrong types, missing fields — all caught at load time with clear errors.

Layered config: file → env → CLI

Real apps need multi-source config. Pattern: defaults from a file, override with env vars, override with CLI flags. Use pydantic-settings:

from pydantic_settings import BaseSettings, SettingsConfigDict
from pathlib import Path

class Settings(BaseSettings):
    nexus_url:   str = "https://nexus.example.com"
    nexus_token: str = ""
    log_level:   str = "INFO"
    max_workers: int = 4

    model_config = SettingsConfigDict(
        env_file=".env",                    # if present
        env_prefix="PROMOTE_",              # PROMOTE_NEXUS_URL etc.
        case_sensitive=False,
    )

s = Settings()
print(s.nexus_url, s.max_workers)

Precedence (highest to lowest): explicit constructor args → env vars → .env file → defaults. Standard for 12-factor apps.

Binary formats — quick mention

For embedded work you'll occasionally hit:

  • MessagePack — JSON-shaped but binary; pip install msgpack. Half the size, much faster.
  • Protobuf — schema-driven, language-agnostic, used heavily in gRPC.
  • FlatBuffers / Cap'n Proto — zero-copy reads, niche.
  • CBOR — RFC-standard binary JSON, used in IoT.

For most automation work, JSON or YAML is fine. Reach for binary only when you're moving GBs or running on constrained hardware.

Hands-on: a release-notes generator

Hands-on · YAML in, Markdown out

Reads a changelog.yaml, validates with Pydantic, emits release notes:

yamlchangelog.yaml
version: "1.4.0"
date: 2026-04-23
sections:
  - title: Added
    items:
      - "Support for iMX8MP wide-temp variant."
      - "OTA delta-update for >100 MB images."
  - title: Fixed
    items:
      - "U-Boot env corruption on power-cut during update (CVE-2026-1234)."
  - title: Changed
    items:
      - "Bumped kernel to 6.6.30 LTS."
pythonscripts/notes.py
#!/usr/bin/env python3
from pathlib import Path
from datetime import date
import sys, yaml
from pydantic import BaseModel, Field

class Section(BaseModel):
    title: str
    items: list[str] = Field(..., min_length=1)

class Changelog(BaseModel):
    version:  str = Field(..., pattern=r'^\d+\.\d+\.\d+$')
    date:     date
    sections: list[Section]

def render(c: Changelog) -> str:
    out = [f"# v{c.version} — {c.date.isoformat()}\n"]
    for s in c.sections:
        out.append(f"## {s.title}")
        for item in s.items:
            out.append(f"- {item}")
        out.append("")
    return "\n".join(out)

def main(path: Path) -> int:
    raw = yaml.safe_load(path.read_text())
    c = Changelog.model_validate(raw)
    print(render(c))
    return 0

if __name__ == "__main__":
    raise SystemExit(main(Path(sys.argv[1])))

Run: ./notes.py changelog.yaml > RELEASE_NOTES.md. The Pydantic model rejects: missing fields, wrong types, malformed version strings, empty sections. The whole "validate untrusted YAML" pattern in 25 lines.

Exercises

EX 4.1 easy JSON gotcha

What's wrong with this and how do you fix it?

data = {"version": "1.0", "build_time": datetime.now()}
text = json.dumps(data)
Show solution

datetime isn't JSON-serialisable. Either pass default=str for a quick fix, or use a custom encoder, or convert before dumping:

data["build_time"] = data["build_time"].isoformat()
text = json.dumps(data)
# or
text = json.dumps(data, default=str)
EX 4.2 easy Norway problem

What does this print, and why?

import yaml
print(yaml.safe_load("country: NO"))
print(yaml.safe_load("version: 1.10"))
Show solution 
{'country': False}
{'version': 1.1}

YAML 1.1 implicit typing: NO is a boolean false, 1.10 is a float. Quote strings: country: "NO", version: "1.10". Or switch to a YAML 1.2 parser.

EX 4.3 medium Pydantic model for K8s-like manifest

Write a Pydantic model that validates this minimal Pod-like spec, requiring a name (DNS-safe), at least one container, and only known restart policies:

name: my-pod
restart: Always
containers:
  - name: app
    image: nginx:1.27
    ports: [80]
Show solution 
from pydantic import BaseModel, Field
from typing import Literal

class Container(BaseModel):
    name:  str   = Field(..., pattern=r'^[a-z][a-z0-9-]{0,62}$')
    image: str
    ports: list[int] = []

class PodLike(BaseModel):
    name:       str   = Field(..., pattern=r'^[a-z][a-z0-9-]{0,252}[a-z0-9]$')
    restart:    Literal['Always', 'OnFailure', 'Never'] = 'Always'
    containers: list[Container] = Field(..., min_length=1)

Bump the image.tag field in this values.yaml from v1.0.0 to v1.1.0 while preserving every comment and the original key order:

# App settings
image:
  repository: registry.example.com/myapp
  tag: v1.0.0          # bumped weekly

Show solution

from pathlib import Path

yaml = YAML()
yaml.preserve_quotes = True

p = Path('values.yaml')

EX 4.5 hard JSONL streaming aggregation

Given a 10 GB JSONL file of events with shape {"ts": "...", "type": "X", "ms": 42}, compute count and average ms per event type, in constant memory.

Show solution 
import json
from collections import defaultdict
from pathlib import Path

counts: dict[str, int] = defaultdict(int)
totals: dict[str, float] = defaultdict(float)

with Path('events.jsonl').open() as f:
    for line in f:
        if not line.strip():
            continue
        e = json.loads(line)
        t = e['type']
        counts[t] += 1
        totals[t] += e['ms']

for t in sorted(counts):
    print(f"{t:<20} n={counts[t]:>8}  avg={totals[t]/counts[t]:.2f}")

Streaming line-by-line + accumulators. Constant memory regardless of file size.

Recap

  • JSON for machines, YAML for humans, TOML for tool config, CSV/JSONL for tabular/streaming.
  • YAML: always safe_load; use ruamel.yaml for comment-preserving in-place edits; quote anything ambiguous to avoid the Norway problem.
  • JSON: pass default= or use a custom encoder for non-trivial types; pass allow_nan=False for strict output.
  • For untrusted input, validate with Pydantic v2 — coercion, regex, range checks, structured errors out of the box.
  • Layered config: pydantic-settings stacks defaults, .env, env vars, and CLI flags.
  • JSONL is the streaming workhorse — pair with generators for constant-memory pipelines.
